# 数据与桌面边界

- Electron 渲染层使用 `contextIsolation:true`、`sandbox:true`、`nodeIntegration:false`，只暴露受限笔记操作接口。
- `yanqian://app` 只提供应用白名单资产，禁用页面外网连接、任意frame、对象和非应用导航。HTTPS外链交给系统浏览器。
- Markdown经过本机DOMPurify；原始HTML显示为文字。笔记没有获取Node或任意文件系统的权限。
- 文件操作限制在当前选择的Markdown目录内，拒绝越界和符号链接；写入采用临时文件替换，预期修订冲突不静默覆盖。原生集成检查使用临时合成目录。
- 删除移动到应用回收区，可恢复；外部文件已变动时，编辑器保留自己的草稿并允许另存副本。
- 默认独立笔记库，不自动扫描其他应用的vault或个人账号。发布源码不含用户笔记、账号信息、厂商原包或服务凭据。
- 当前未实现网络同步、多人协作或插件执行。不能把隔离测试等同于所有恶意环境安全保证。
- `npm audit --omit=dev`运行时依赖核验与构建工具链核验分开记录。构建工具的告警不能被描述为已全部解决。

如发现问题，请先备份自己的Markdown目录，并在项目仓库报告最小复现（不要提交私密笔记或凭据）。
